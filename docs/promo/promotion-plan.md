# Mini-Tools.uk Promotion Plan

## Core Positioning

Mini-Tools.uk is a lightweight collection of practical UK calculators and browser-first tools. It is useful for people who need quick answers without creating an account, installing software, or uploading sensitive text and files when local browser processing is enough.

Primary message:

> Free UK calculators and browser tools for tax, VAT, mortgages, JSON, images, PDFs, QR codes, passwords, and everyday admin.

## Target Audiences

- UK employees, contractors, directors, landlords, home buyers, and small business users.
- Developers who need quick JSON formatting, text diffing, AI token estimation, image compression, and QR generation.
- Bloggers, open-source maintainers, and forum users who need simple image hosting and Markdown-ready links.
- Chinese-speaking users in the UK who need bilingual UK tax and calculator utilities.

## Best Launch Angles

1. **Practical UK calculator hub**
   - Focus: tax, VAT, mortgage, stamp duty, IR35, dividend, working days.
   - Best channels: UK finance communities, contractor communities, indie hacker updates, SEO directories.

2. **Browser-first privacy-friendly utilities**
   - Focus: JSON, diff, image compression, PDF to PNG, password generator.
   - Best channels: developer communities, GitHub README, Hacker News style posts, dev forums.

3. **Tools for README, Markdown, and content publishing**
   - Focus: free image hosting, QR codes, image compression, color picker.
   - Best channels: GitHub users, bloggers, Markdown communities, open-source maintainers.

## External Posting Checklist

- Product Hunt: submit as a practical tool directory.
- Hacker News: use the developer and browser-local angle.
- Reddit: only post where self-promotion is allowed; lead with usefulness, not hype.
- V2EX: post in relevant nodes such as programmer, share, or UK-related communities if appropriate.
- Twitter/X: short launch thread with tool categories and direct links.
- LinkedIn: focus on UK finance/admin productivity and small business workflows.
- Indie Hackers: frame it as a lightweight static site of practical tools.
- GitHub communities: share the image hosting, Markdown, JSON, and developer tools angle.

## Posting Rules

- Do not spam the same message across unrelated communities.
- Adapt each post to the platform.
- Always disclose that the site is your project.
- Prefer one useful tool link per post when a community has a narrow topic.
- Avoid claiming tax, finance, or legal advice; use words like estimate, calculator, assumptions, and practical reference.

## Success Metrics

- GitHub stars and repository visits.
- Search Console impressions and clicks for individual tool pages.
- Direct traffic to top tools.
- Repeat usage for calculators and developer tools.
- Feedback issues created in the GitHub repository.
