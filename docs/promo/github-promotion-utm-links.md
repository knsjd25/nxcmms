## Recommended UTM use

- Use `comment` links for issue, pull request, and discussion replies.
- Use the shared `readme` link in your own README, docs page, or resource list.
- Use `discussion` only when GitHub Discussions are enabled and the post is allowed.
- Use `release` only when mentioning the tool in your own release notes.
- Do not mix country campaigns in the same comment. Keep the campaign aligned with the language of the message.
