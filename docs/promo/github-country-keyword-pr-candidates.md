# GitHub Country Keyword and PR Candidate Matrix

Scope: GitHub-only promotion for the Mini-Tools.uk image hosting page.

Target page:

`https://mini-tools.uk/upload`

Core product angle:

Upload an image and generate a direct URL, Markdown image code, HTML image tag, and BBCode snippet for README files, docs, GitHub issues, pull requests, blogs, and forums.

## Guardrails

- Do not open PRs in unrelated repositories.
- Do not open issues just to advertise the tool.
- Only submit PRs to curated lists that already accept online tools, Markdown tools, README resources, image tools, or developer utilities.
- Skip country/language repositories that are about NLP, datasets, local communities, jobs, public administration, or unrelated open-source projects.
- Keep each PR to one small README list entry.
- Do not submit the same entry to many low-quality forks.
- If a repository says it does not accept generic toolboxes, skip it.

| Score | Condition | Action |
| --- | --- | --- |
| 3 | Curated online tools/image tools list, active repo, existing similar entries. | Good PR candidate. |
| 2 | Markdown/README/developer tools list, but no image hosting section. | Manual review before PR. |
| 1 | Accepts project recommendations through issues only. | Ask before issue; do not PR. |
| 0 | Personal project, NLP list, datasets, local community list, job list, or unrelated repo. | Skip. |
