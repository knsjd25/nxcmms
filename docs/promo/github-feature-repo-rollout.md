## Repository Pattern

Each feature repository should contain:

- `README.md`
- `docs/index.md`
- `docs/{language-code}.md` for 50+ languages
- Related search keywords
- Natural long-tail keyword phrases

Each repository should focus on one tool feature only. Do not mix unrelated mini-tools.uk tools in the same repository.

## Content Rules

- Link to the relevant mini-tools.uk tool page.
- Keep each page focused on the specific feature.
- Include local-language search terms naturally.
- Include long-tail terms for specific user intents, such as "without signup", "online", "free", "for README", "for website upload", or "for documentation" when they match the tool.
- Mention practical use cases.
- Do not claim private/local processing unless the specific tool actually works that way.
- Do not add API endpoints, upload result pages, or temporary URLs.
