# 30-Day GitHub Promotion Plan: Korea, Japan, Vietnam, English/India/Global

Goal:

Promote mini-tools.uk/upload as a practical image URL tool for GitHub README, Markdown docs, issues, pull requests, blogs and forums. This plan uses low-volume, relevant, human replies only.

Core tracked link for English / India / Global:

https://mini-tools.uk/upload?utm_source=github&utm_medium=comment&utm_campaign=image-hosting-en

## Daily posting limits

- New GitHub account: 3 to 5 comments per day.
- Normal account: 5 to 10 comments per day.
- Do not post the same sentence repeatedly.
- Do not comment on unrelated repositories.
- Do not comment multiple times in the same repository in a short period.
- Prefer answering real questions first, then add the tool link only when useful.

## Suitable repository types

- README template repositories.
- Markdown docs repositories.
- Documentation generators.
- GitHub profile README resources.
- Static site and blog template repositories.
- Developer tool lists that accept useful single-purpose tools.
- Issues where users ask how to add images, screenshots, direct links, HTML img tags, or Markdown images.

## Anti-spam rules

- Do not post ads in bulk.
- Do not comment on unrelated repositories.
- Do not copy the same sentence across many issues.
- Do not impersonate maintainers.
- Do not use fake accounts.
- Do not send private messages to promote the tool.
- Do not hard-pitch under old closed issues.
- Do not promise unlimited or indefinite free hosting or retention.
- Do not post when the user clearly does not need an image link.
- Do not make many comments in a short time.

## Recommended behavior

- Reply only where the question is relevant.
- Solve the user's problem first, then mention the tool link.
- Rewrite each comment based on the repository context.
- Prioritize README, docs, issue screenshot, and Markdown image problems.
- Test each market for 7 days before scaling.
- Use UTM data to decide which market and keyword set should continue.
