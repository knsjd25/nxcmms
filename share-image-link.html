Do not treat temporary image links as permanent assets in long-lived README files. Long-term use needs approved permanent storage on /upload.

If the image does not display

  1. Direct link fails: confirm the Direct URL opens alone in a new tab.
  2. Wrong format: confirm the destination accepts the format you pasted (Markdown vs HTML vs BBCode).
  3. Expired temporary upload: if retention was temporary, check whether the retention period has ended.
  4. Destination blocks remote images: some sites block hotlinking or strip remote images via CSP or moderation filters.

FAQ

Which format should I copy first?

Start with Direct URL to verify the image loads, then choose Markdown, HTML or BBCode for the destination.

Are Markdown/HTML/BBCode returned by the API?

No. The API returns fields such as success and url. The web upload page builds share formats from the URL in the browser.

Why does Markdown work but HTML does not?

The destination may allow Markdown image syntax while blocking raw HTML tags.

Can I reuse this demo URL forever?

It is a site-maintained asset for format comparison. For your content, upload your own file on /upload.

Where do I read about expiry?

See Temporary Image Upload. This page only covers embed formats.
