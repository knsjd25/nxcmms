Questions

FAQ

What is Mini-Tools.uk?

Mini-Tools.uk is a collection of simple online tools for calculations, developer tasks, image utilities, PDF tasks and everyday quick work.

Are Search Tools free?

Most tools are free to use without an account.

Do Search Tools run in the browser?

Many tools run in the browser. Some upload or hosting tools may use a remote service, and those pages explain how they work.

Why are some tools shown as popular?

Popular tools are shown for quick access. They are not the only important tools on the site.

Can I suggest a new tool?

Yes. Use the Contact page to send a tool idea or report a problem.
