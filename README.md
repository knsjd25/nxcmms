# Mini-Tools.uk

Free UK calculators and browser-first online tools for everyday admin, developer work, images, PDFs, QR codes, passwords, and more.

Website: https://mini-tools.uk/

## What It Includes

### UK Calculators

- UK take-home pay calculator 2026/27: https://mini-tools.uk/tax
- UK VAT calculator: https://mini-tools.uk/vat
- UK mortgage repayment calculator: https://mini-tools.uk/mortgage
- Stamp Duty Land Tax calculator: https://mini-tools.uk/stamp-duty
- IR35 inside vs outside calculator: https://mini-tools.uk/ir35
- Salary vs dividend calculator: https://mini-tools.uk/dividend
- UK fuel cost calculator: https://mini-tools.uk/fuel
- Stones, pounds, and kilograms converter: https://mini-tools.uk/weight
- UK working days calculator: https://mini-tools.uk/working-days

### Developer And Text Tools

- JSON formatter, validator, minifier, and tree viewer: https://mini-tools.uk/json
- Side-by-side text diff checker: https://mini-tools.uk/diff
- AI token counter and API cost calculator: https://mini-tools.uk/token

### Image, PDF, And Utility Tools

- Image resizer, compressor, cropper, and converter: https://mini-tools.uk/image
- Free image hosting for GitHub README, Markdown, blogs, and forums: https://mini-tools.uk/upload
- PDF to PNG converter: https://mini-tools.uk/pdf2img
- Image color picker: https://mini-tools.uk/color-picker
- QR code generator: https://mini-tools.uk/qr
- Random password generator and strength checker: https://mini-tools.uk/password

## Why Mini-Tools.uk

- No account required for most tools.
- Practical tools focused on common UK, developer, and content workflows.
- Many file and text tools run locally in the browser.
- Clean single-purpose pages with direct URLs.
- Built as a lightweight static site.
