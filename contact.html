How to request hosted image removal

If you are reporting an image hosted by Mini-Tools.uk, include enough information to identify and review the content. Please do not attach extra private documents unless they are necessary to explain ownership or rights.

1
Include the hosted image URL Paste the exact Mini-Tools.uk image link or the page where the image appears.
2
Explain the reason Examples include privacy concern, copyright issue, illegal content, unsafe content, impersonation or policy violation.
3
Add relevant rights information If the request is about ownership, copyright or personal privacy, briefly explain your connection to the image.

What to include in a bug report

A useful bug report does not need to be long, but it should make the problem reproducible. If you are reporting a calculator issue, include the inputs and expected result. If you are reporting an upload issue, include the file type, approximate file size and browser if relevant.

1
The page URL or tool name This helps identify whether the problem is on a calculator, developer tool, image tool or information page.
2
What you expected and what happened A short before-and-after explanation makes bugs easier to reproduce.
3
Device, browser or screenshot if useful Some issues only appear on certain screens, browsers, file types or language settings.

Before sending sensitive material

Some Mini-Tools.uk pages process data locally in the browser, while image hosting and sharing features may use remote services. Email is not the right place for secrets or highly sensitive personal information.

Do not email passwords, API keys, payment details, identity documents, private financial documents, credentials or anything you would not want stored in a normal email inbox.

Can I request removal of a hosted image?

Can I report a calculation issue?

Yes. Include the page URL, the input values you used, the result you received and what result you expected.

Should I email private data?

No. Keep contact messages focused on the issue itself and avoid sending credentials, payment details, API keys or highly sensitive personal information.
