What to include in a helpful message

The clearer the message, the easier it is to investigate. If you are reporting a problem, please include details rather than only saying that something is broken.

1
The page name or URL This helps identify the exact tool or content page quickly.
2
What you expected and what happened A short before-and-after explanation makes bugs easier to reproduce.
3
Device, browser or screenshot if relevant Some issues only appear on certain screens, browsers or file types.

Before sending sensitive material

Some Mini-Tools.uk pages process data locally in the browser, while other features may use remote services for uploads or sharing. Email is not the right place for secrets or highly sensitive personal information.

Please do not send passwords, API keys, payment details, private documents, credentials or anything you would not want stored in plain email.

Can I report a calculation issue?

Yes. Include the page URL, the input values you used, the result you received and what result you expected.

Can I suggest a new tool?

Yes. Please describe the task, expected input, expected output and a simple example of how the tool should work.

Should I email private data?

No. Keep contact messages focused on the issue itself and avoid sending credentials, payment details or highly sensitive personal information.
